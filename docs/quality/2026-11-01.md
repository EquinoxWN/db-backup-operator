# Quality check against the 10 rules (2026-11-01)

Checked on Windows 11 with Go 1.26.10. Unit tests use a fake API client and a fake pod executor;
the race detector (needs cgo, not installed here) and the three envtest tests run in CI on Linux.

## Rules

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Assume every call can fail | pass | Pod exec calls are bounded: `backupTimeout` (2 h) for `wal-g backup-push`, `queryTimeout` (30 s) for `psql` (`backuppolicy_controller.go`). Every API error is returned to controller-runtime, which requeues with its rate limiter's exponential backoff; a missing primary requeues after `retryAfter` (1 min). `go vet ./...` clean; no ignored errors. |
| 2 | Writes safe to retry | fixed | Defect found: after a backup, a conflict on the status write (the policy was edited during a backup that can take 2 h) returned an error before `lastScheduleTime` was stored, so the next reconcile ran the same backup again. `saveStatus` now re-reads the policy and writes the computed status again on a conflict (`retry.RetryOnConflict`, `retry.DefaultRetry`: 5 bounded attempts). Test: `TestAStatusConflictAfterABackupDoesNotRunItAgain` (fails before the fix with "object was modified"). Missed runs collapse into one backup (`TestMissedRunsCollapseIntoOneBackup`). |
| 3 | No race conditions | pass | The reconciler keeps no shared mutable state; controller-runtime reconciles one policy at a time. CI runs `go test -race ./...`. |
| 4 | Don't trust the clock | pass | Schedules are wall-clock by design (cron) and are evaluated in UTC (`dueTime`, regression test `TestScheduleIsUTCWhateverTheLocalTimeZone`); stored times are UTC `metav1.Time`. No durations are measured. |
| 5 | Read before changing | pass | No env vars of its own; flags are listed by `--help` and in the README. `retry.RetryOnConflict` is from `k8s.io/client-go/util/retry` v0.35.10, already a direct dependency (`go.mod` unchanged). |
| 6 | Never break compatibility | pass | CRD and status fields unchanged (`make verify-generated` in CI). |
| 7 | One source of truth | pass | CRD and RBAC are generated from the Go types and markers and checked in CI. Go 1.26.10 agrees in README, `go.mod` and CI. |
| 8 | Small changes, no secrets, validate input | pass | No secrets. The policy is validated by the CRD schema (envtest rejects 6 bad policies); commands are argv, never a shell string; `psql` output is parsed strictly (new tests for an extra column and a non-numeric `failed_count`). |
| 9 | Tests that can actually fail | fixed | The three `t.Skip` calls are documented (`KUBEBUILDER_ASSETS not set; run make envtest`, run in CI). 16 hand mutations below: 8 of 14 original mutants survived and now have tests. |
| 10 | Re-verify | pass | `gofmt -l`: nothing. `go vet ./...`: clean. `go test -count=1 ./...`: `ok .../internal/controller` (13 passed, 3 envtest skipped locally). `govulncheck@v1.8.0 ./...`: `No vulnerabilities found.` `audit_repo.py db-backup-operator`: `OK`. |
